# Results

This folder is intended for result files generated after running the MATLAB workflow.

The script creates a local folder called:

```text
Project_Output/
```

Expected result files:

| File | Description |
|---|---|
| `Differential_Expression_Results.xlsx` | Differential expression table including logFC, p-value, adjusted p-value, and regulation status |
| `Treatment_Scenario_Summary.xlsx` | Summary of final model values under different treatment strengths |
| `Project_Summary.txt` | Short biological and numerical project summary |

These files can be uploaded here after running the script if the project needs to include final outputs.
