# Project Summary

## Title

MATLAB-Based Numerical Simulation of BCR-ABL1 Expression Dynamics and Targeted Therapy Response in Chronic Myeloid Leukemia

## Summary

This project uses MATLAB to simulate simplified CML-related dynamics and targeted therapy response. It combines numerical ODE modeling with gene expression analysis to demonstrate how computational biology can be used to represent cancer-related molecular behavior.

## Core Idea

CML is driven by the BCR-ABL1 fusion gene, which produces abnormal kinase activity and supports leukemic cell survival. The model represents treatment as a parameter that reduces leukemic cell growth or survival over time.

## Main Components

1. Gene expression data loading and preprocessing.
2. Differential expression analysis between CML and reference groups.
3. Visualization using boxplot, bar plot, volcano plot, and heatmap.
4. ODE-based simulation of leukemic cells, healthy cells, and mRNA signal.
5. Numerical comparison between Euler’s Method, RK4, and MATLAB ode45.
6. Treatment scenario comparison using different treatment strengths.
